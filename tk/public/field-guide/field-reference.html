1. Scope and method

A data collection point is any place where a value enters a system: a question on a form, a sensor reading, a scanned code, an automatically stamped timestamp, a file attached to a record, or a message received over a channel. This document groups them into 16 families and then shows which tools support each.

How to use it. Start with the master catalogue (section 2) and filter by tool or keyword. Use section 3 when writing XLSForms for KoboToolbox or ODK. Use sections 5 to 7 to choose tools and controls. Section 9 applies everything to a healthcare training college ERP.

    4. Tool profiles

    Each profile lists what the tool adds beyond the common set of text, number, choice, date, location and media inputs.

    KoboToolbox and KoboCollect

    Unique points
    Matrix, score and rank blocks; qualitative analysis of open text; validation statuses per submission; notes and tags; bulk edit in the web data table; data gallery and map views; per-project permissions with anonymous submission options.
    Channels
    KoboCollect (Android, offline), Enketo web forms (public or authenticated link, iframe embed, offline-capable), web data entry, REST API v2, import, REST Services (webhooks).
    Exports
    XLS, CSV, KML, GeoJSON, SPSS, media ZIP, live feeds.
    Watch-outs
    No built-in case management; Android-only mobile app; shared public servers have storage and submission limits; phone and SIM metadata is mostly blank on new devices.

    ODK: Collect, Central, Build, Web Forms

    Unique points
    Entities (dataset records created or updated from submissions, including offline), form-level encryption, draft forms, app users, public access links, submission review states and edit, audit logs, OData feeds, attachments and external CSV lookups, in-app map drawing, osm tags.
    Channels
    ODK Collect (Android), web forms in the browser, Central REST API and OData, bulk upload.
    Watch-outs
    You host Central yourself or use a hosted plan; check feature parity between Collect and web clients.

    ODK-X

    Unique points
    Relational tables with row-level sync and conflict handling, custom HTML and JavaScript applications, sensor framework for Bluetooth and USB devices, fine-grained user roles.
    Best for
    Complex longitudinal field work where a plain survey form is too limited.

    SurveyCTO

    Unique points
    Text audits and audio audits, sensor streams and statistics (sound, light, movement, pressure), plug-in field types, field-level encryption, case management datasets, review and correct workflows, built-in quality monitoring dashboards, enumerator performance checks, server datasets for lookups.
    Channels
    Android app, web forms, API, data exports, publishing to external systems.
    Watch-outs
    Commercial licence; its form language is close to but not identical to XLSForm.

    CommCare (and CommCare Connect)

    Unique points
    Case management (case types, properties, parent-child indexes, case sharing), mobile worker and location hierarchy, lookup tables, case search and claim, conditional alerts, SMS and voice workflows, data forwarding, app callouts to other Android apps, biometric identification through partner integrations, field worker verification and payment through Connect.
    Channels
    Android app, Web Apps, SMS, IVR, API, exports.
    Best for
    Ongoing client or household follow-up, community health programmes.

    Epicollect5

    Unique points
    Hierarchical forms up to five levels, branches (child entries), entry titles built from up to three fields, jumps, uniqueness rules (per form, hierarchy or none), regex checks, searchable single and multiple selects, read-me text blocks, public or private projects.
    Channels
    Android and iOS apps, bulk upload, API, web data browsing and maps.
    Watch-outs
    No calculations; lighter logic than XLSForm tools; no polygon capture.

    ArcGIS Survey123

    Unique points
    Direct write to ArcGIS feature layers, related tables, GNSS metadata (fix type, satellites, accuracy, receiver), external Bluetooth GNSS receivers, offline basemaps, geocoder search, image annotation, report templates, inbox, drafts and outbox workflow.
    Channels
    Field app (iOS, Android, Windows), web app, Survey123 Connect for XLSForm authoring.

    REDCap

    Unique points
    Data entry forms and public surveys on the same data model; repeating instruments and longitudinal events and arms; data access groups; validation types (date, email, integer, number, phone, postal code and more); action tags; calculated fields; visual analogue sliders; e-consent framework; randomisation module; data quality rules; dynamic data pull; EHR integration (FHIR); audit trail; shared library of validated instruments; MyCap participant app; SMS and voice through Twilio; survey queue and automated invitations; scheduling.
    Channels
    Web, REDCap Mobile App (offline), MyCap, API, external modules.
    Best for
    Research and clinical-style data capture.

    DHIS2

    Unique points
    Aggregate: data elements, category option combinations (for example age by sex), data sets, reporting periods, organisation units, validation rules, completeness, approval. Tracker: tracked entity types and attributes, programs, enrolments, program stages (repeatable), events, relationships, notes, program rules, indicators. Value types include text, long text, boolean, true-only, date, date-time, time, number, integer (plain, positive, negative, zero-or-positive), percentage, unit interval, age, phone number, email, URL, coordinate, organisation unit, username, file, image, GeoJSON, multi-text.
    Channels
    Web apps, Android Capture app, SMS commands, CSV, JSON, ADX imports, API.

    Survey Solutions (World Bank)

    Unique points
    Interview workflow with interviewer, supervisor and headquarters roles; nested rosters; numeric, text, date, single and multi-select, yes/no, text list, GPS, picture, audio, QR code and area (polygon) questions; variables and static text; assignments; paradata.
    Channels
    Interviewer tablet app, web interviews, API.

    CSPro

    Unique points
    Dictionary-driven census and survey data entry; records and occurrences; CAPI on Android and Windows; GPS, barcode, audio, photo; map display; paradata; Bluetooth and CSWeb synchronisation; data entry from paper.
    Best for
    National statistical offices and very large structured surveys.

    Fulcrum

    Unique points
    Classification sets, record links, addresses, hyperlinks, repeatable sections, calculations, record assignment and status, webhooks, map-centred inspection work.

    Qualtrics

    Unique points
    Matrix, slider, rank order, side-by-side, constant sum, pick-group-rank, hot spot, heat map, drill-down, MaxDiff, conjoint, file upload, signature, timing, captcha, text and graphic; embedded data; randomiser and quotas; automatic response metadata (start and end time, duration, progress, IP address, approximate location, browser, operating system, screen resolution, language, distribution channel).

    Google Forms and Microsoft Forms

    Unique points
    Short answer, paragraph, multiple choice, checkboxes, dropdown, linear scale, rating, grids, date, time, file upload, Likert and ranking (Microsoft), net promoter score (Microsoft), sections with branching, quiz mode with marking, respondent email capture, response validation.
    Watch-outs
    Online only; no location, barcode, repeat groups or offline mode.

    Jotform, Typeform, Tally and similar builders

    Unique points
    Payment fields, e-signature, appointment pickers, product lists, address autocomplete, widgets, conditional logic, calculations, hidden fields, integrations with spreadsheets and CRMs.

    Community Health Toolkit (Medic)

    Unique points
    XLSForm-based app forms, contact hierarchy (health worker, family, person), tasks and targets generated from submissions, SMS, offline-first progressive web app.

    OpenMRS (electronic medical records)

    Unique points
    Patient registration with identifiers, attributes, addresses and relationships; encounters and visits; observations typed by concept (numeric, coded, text, date, time, date-time, boolean, document, complex); orders for drugs and tests; programs and enrolments; FHIR API.

    Moodle and other learning platforms

    Unique points
    Quiz items (multiple choice, true/false, matching, short answer, numerical, essay, calculated, drag and drop, cloze), assignment file and text submissions, workshops, forum posts, attendance, completion tracking, grade items, H5P, SCORM and xAPI events, activity logs.

    8. Consent, security and legal considerations

    Each point below is itself something you collect, store or decide when you design a form.

    • Consent record. Consent text (note), acknowledgement tick, signature or thumbprint, date and time, language used, witness name, and who obtained consent. For minors, guardian consent plus assent where appropriate.
    • Purpose and lawful basis. Record why each field is collected. Drop fields without a purpose (data minimisation).
    • Personal data classification. Tag each field as direct identifier, indirect identifier, sensitive or non-personal. Health, biometric and similar data are generally treated as sensitive.
    • Encryption. In transit (HTTPS), on device (app and disk encryption), at rest on the server, and optionally at form level (ODK public key; SurveyCTO field-level).
    • Access control. Roles for enumerators, supervisors, analysts and administrators; project-level and row-level permissions; two-factor sign-in for admins.
    • Location privacy. Decide whether to store exact coordinates, rounded coordinates or only an administrative area. Remove or jitter coordinates before sharing datasets.
    • Media handling. Rules on photographing people, faces, documents and minors; automatic deletion of recordings after review.
    • Retention and deletion. Retention period per data type, deletion requests, backup expiry.
    • Audit trail. Log sign-ins, exports, edits, permission changes and deletions.
    • Data sharing. Data sharing agreements, anonymised extracts, controlled-access repositories.

    Kenya. The Data Protection Act, 2019 governs personal data. Its core duties include lawful and fair processing, purpose limitation, data minimisation, accuracy, storage limitation and security safeguards. It gives data subjects rights of access, correction and erasure, and imposes registration with the Office of the Data Protection Commissioner for many controllers and processors. It also sets conditions on processing children's data and sensitive personal data, and on transfers outside Kenya. Health-sector rules (for example the Digital Health Act, 2023) and professional council requirements may add further duties. This is a summary, not legal advice; confirm obligations with your legal counsel or data protection officer.

    9.3 Design rules that prevent most problems

    • Give every record a stable ID created once and never reused (student, staff, facility, course, asset).
    • Keep lookup lists (programmes, facilities, procedures) in one place and push them to forms; avoid retyping.
    • Store raw submissions untouched, then clean in a separate layer so corrections are traceable.
    • Capture form version, device, user and submission time with every submission.
    • Separate sensitive data (health, disability, biometrics) into restricted tables with their own permissions.
    • Use controlled vocabularies for anything you will report on later.
